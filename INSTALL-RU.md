# Установка и обновление — ULT's Loading Screen (`ult-ls`) 1.4.1

## Установка в Foundry (рекомендуется)

1. В Foundry откройте **Add-on Modules → Install Module**.
2. В поле **Manifest URL** вставьте:
   ```
   https://github.com/x4isfate/ult-ld/releases/latest/download/module.json
   ```
3. Нажмите **Install**, затем включите модуль в мире (**Manage Modules**).

Дальше новые версии приходят обычной кнопкой **Update** в списке модулей — вручную ничего копировать не нужно.

## Если стоит старая версия `ult-ld`

Идентификатор модуля изменился с `ult-ld` на `ult-ls`. Это два разных модуля для Foundry.

1. Установите новую версию по инструкции выше и включите её.
2. Зайдите в мир **как Мастер**. Настройки, подсказки и список сцен старой версии скопируются автоматически (появится уведомление), после этого перезайдите в мир.
3. Отключите старый модуль `ult-ld` в **Manage Modules** и при желании удалите его папку из `Data/modules/`.

Пока старая копия включена, Мастер увидит предупреждение: два экрана загрузки мешают друг другу.

## Установка вручную (без интернета)

1. Закройте Foundry.
2. Распакуйте архив `ult-ls-1.4.1.zip` в папку данных Foundry так, чтобы получилось:
   ```
   Data/modules/ult-ls/module.json
   ```
   Не `ult-ls/ult-ls/module.json` — вложенная папка не подходит.
   - **Windows:** `%localappdata%\FoundryVTT\Data\modules\`
   - **Linux:** `~/.local/share/FoundryVTT/Data/modules/`
   - **macOS:** `~/Library/Application Support/FoundryVTT/Data/modules/`
3. Запустите Foundry и включите модуль.

Проверить версию: в консоли (F12) выполните `game.modules.get("ult-ls").version` — должно вернуть `"1.4.1"`.

## Первые шаги

Откройте **Configure Settings → ULT's Loading Screen → Открыть Центр настроек** (или кнопку с песочными часами в панели токенов слева). Все настройки собраны в этом окне, сверху — живой предпросмотр.

- Начните с вкладки **Палитра** и выберите тему, затем **Вид и стиль**, затем **Фон и иконка**.
- Изменения предпросмотра видны сразу. Для показа на реальном экране загрузки большинство настроек требуют перезахода в мир — в левом нижнем углу окна появится значок перезагрузки.
- **Пресеты**: сохранить все настройки в файл, загрузить чужой пресет или сбросить всё.
- **Личная тема игрока**: на вкладке **Видимость** включите «Разрешить игрокам выбирать свою тему». Игроки увидят в настройках модуля свою кнопку, а также кнопку в панели токенов.

### Свой фон, иконка, звук

Файл выбирается кнопкой с папкой рядом с полем. Если картинка или звук не появляются:

1. Включите **Отладочный лог** (вкладка «Видимость»), перезайдите в мир и откройте консоль (F12). Там будет итоговый путь к файлу и причина, почему он не загрузился.
2. Убедитесь, что папка с файлом доступна в **Configure Settings → File Sources** (по умолчанию `Data`, включая `modules/…` и папку мира).
3. Положите файлы, например, в `Data/modules/ult-ls/assets/` или в папку мира.

**Про запуск звука.** Браузеры разрешают звук только после клика, касания или нажатия клавиши на странице. Это правило самого браузера: обойти его не может ни один модуль, а собственный звук Foundry подчиняется ему же. Пока браузер блокирует звук, на экране загрузки видна подсказка «Нажмите в любом месте, чтобы включить звук», и звук начинается с первого клика. Полностью убрать этот клик можно так:
- В **приложении Foundry** такого ограничения нет.
- В **Chrome** звук сам начинает играть без клика, когда браузер «привыкает» к адресу вашего Foundry: у него есть оценка вовлечённости сайта (её видно на странице `chrome://media-engagement`), и она растёт, когда на этом адресе регулярно воспроизводятся звуки, например плейлисты.
- В **Firefox** в настройках сайта можно разрешить «Автовоспроизведение: разрешить звук и видео».

## Как выпустить следующую версию на GitHub

Репозиторий: <https://github.com/x4isfate/ult-ld>

Релиз собирается автоматически: достаточно поднять версию и создать тег.

1. В `module.json` поднимите `"version"` (например, до `1.4.1`), в `CHANGELOG.md` допишите изменения, а в `scripts/changelog.js` и `lang/*.json` — текст для окна «Что нового» (если оно нужно для этой версии).
2. Залейте изменения на GitHub (`git add .`, `git commit`, `git push`).
3. Создайте тег с тем же номером и отправьте его:
   ```
   git tag v1.4.1
   git push origin v1.4.1
   ```
4. Через минуту на странице **Releases** появится релиз `v1.4.1` с файлами `module.json` и `ult-ls.zip`. После этого Foundry покажет кнопку **Update**.

Если номер в теге и в `module.json` разный, сборка остановится с понятной ошибкой — так нельзя случайно выпустить неверную версию. Статус сборки виден на вкладке **Actions**.
